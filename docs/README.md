# Documentation notes

## Purpose

These pages explain how each simulation works for both learners and maintainers.

## Writing conventions

- Keep explanations brief and practical.
- Use British English.
- State units for all parameters.
- If a control only applies on reset, say so explicitly.
- Distinguish user-facing labels from internal engine variables where needed.

## Update checklist (when editing a simulation)

1. Update equations if model changes.
2. Update parameter table if controls/defaults/ranges change.
3. Update engine notes if implementation choices change.
4. Verify the module page link still exists in that simulation's nav.
