Field truth

detection function used to simulate whether each animal is detected; governs the true shape of g(x)

Model

⚠ Model mismatch — D̂ may be biased

detection function used by the MLE estimator to fit σ̂ and compute D̂; mismatching Field truth introduces bias

σ 0.25 km

detection scale (km): for half-normal, the distance at which g(x) ≈ 0.61; updates live

W 0.50 km

truncation distance (km): animals beyond W are never detected; the analysis also ignores detections past this distance; updates live

b (shape) 2.5

hazard-rate shape: higher b gives a wider flat shoulder near the transect before a sharper drop; updates live

D 50 /km²

true animal density (animals per km²): sets how many animals are placed; takes effect on Reset

L 4.0 km

transect length (km): sets the width of the arena and total survey effort; takes effect on Reset

Distribution

spatial distribution of animals: Uniform = random, Clustered = aggregated groups, Regular = over-dispersed grid; takes effect on Reset

s_clump 0.10

cluster spread as a fraction of transect length: larger values create looser, more spread-out groups

ρ (regularity) 0.50

grid jitter: 0 = animals sit exactly on grid points, 1 = maximum random displacement within each cell

σ, W, detection functions and b update live. All other parameters take effect on Reset.
